P0: 🔬 DOMAIN CONTEXT
P1: This project is for Vikram Sarahai Space Centre (VSSC / ISRO). M250 Maraging Steel is used in aerospace launch vehicle thin-shell structures joined by TIG welding (LSLF — Longitudinal Seam Launch and Finish). Weld quality degrades through repair cycles:
P2: R0 = Original weld (UTS ~1585–1650 MPa, YS ~1550–1596 MPa, KIC ~75 MPa√m)
P3: R1 = First repair (UTS ~1510–1610 MPa, YS ~1475–1565 MPa)
P4: R2 = Second repair (UTS ~1448 MPa, YS ~1366 MPa) — the prediction target
P5: The objective: given R0 measurements (and optionally R1), predict R2 UTS, Yield Strength, and a complete smooth stress-strain curve for R2, with maximum possible accuracy. This lets engineers guarantee minimum R2 properties without destructive testing.
