🔬 DOMAIN CONTEXT
This project is for Vikram Sarahai Space Centre (VSSC / ISRO). M250 Maraging Steel is used in aerospace launch vehicle thin-shell structures joined by TIG welding (LSLF — Longitudinal Seam Launch and Finish). Weld quality degrades through repair cycles:
R0 = Original weld (UTS ~1585–1650 MPa, YS ~1550–1596 MPa, KIC ~75 MPa√m)
R1 = First repair (UTS ~1510–1610 MPa, YS ~1475–1565 MPa)
R2 = Second repair (UTS ~1448 MPa, YS ~1366 MPa) — the prediction target
The objective: given R0 measurements (and optionally R1), predict R2 UTS, Yield Strength, and a complete smooth stress-strain curve for R2, with maximum possible accuracy. This lets engineers guarantee minimum R2 properties without destructive testing.

🧠 FULL ML + DL PIPELINE
Model Architecture — train ALL of the following and ensemble them:
A. Classical ML Models (sklearn / xgboost / lightgbm):
Extra Trees Regressor
Random Forest Regressor
XGBoost with early stopping
LightGBM
Gradient Boosting Regressor
B. Deep Learning Models (PyTorch or TensorFlow/Keras — choose whichever installs cleanly):
1D-CNN Regressor: 
Treat the 5 (or 9 with R1) input features as a 1D sequence
Architecture: Conv1D(64, kernel=3) → ReLU → Conv1D(128, kernel=3) → GlobalMaxPool → Dense(64) → Dense(2)
BatchNorm after each conv, Dropout(0.3) before final dense
Bidirectional LSTM Regressor: 
Reshape features as a sequence (each feature = one time step, value = feature value)
Architecture: BiLSTM(128) → BiLSTM(64) → Dense(32) → Dense(2)
Dropout(0.2) between LSTM layers
Use this for predicting R2 UTS and YS from R0/R1 scalars
Transformer Regressor (self-attention over features): 
Treat each input feature as a token with a learned embedding
Multi-head self-attention (4 heads) → LayerNorm → FFN(128) → Dense(2)
Positional encoding applied to feature tokens
This allows the model to learn which R0 properties most influence R2 degradation
CNN + LSTM Hybrid: 
Conv1D(64) → MaxPool → BiLSTM(64) → Dense(2)
Best of both: local pattern detection + sequential dependency
C. Meta-Learner Stacking Ensemble:
Train all models above on 80% data
Use their out-of-fold predictions as inputs to a Ridge regression meta-learner
Final predictions = meta-learner output
This typically achieves R² > 0.99 on this type of structured materials data
D. LSTM Stress-Strain Curve Generator (separate model):
Trained on Option B dataset (curve shape parameters)
Input: R0 curve parameters (elastic slope, yield strain, UTS strain, fracture strain, yield stress, UTS, hardening ratio, area)
Output: predicted R2 curve parameters (yield strain, UTS strain, fracture strain, yield stress, UTS, area)
Architecture: LSTM(64) → Dense(32) → Dense(6 outputs)
After predicting curve parameters, use scipy Pchip interpolation to reconstruct the full smooth stress-strain curve
Hardcode reference curve data points from known experimental values: 
Parent Material: from strain=0 to strain=0.016634, stress peaking ~1800 MPa
R0: strain to ~0.014234, stress to ~1585 MPa
R1: strain to ~0.015434, stress to ~1515 MPa
R2 reference: strain to ~0.016634, stress to ~1448 MPa
Use the exact tabular data visible in the project (R2 columns from image: strain values 0.002375→0.016634, stress 451.06→1448)
E. Uncertainty Estimation:
Implement Monte Carlo Dropout on the DL models: run inference 50 times with dropout ON, report mean ± 2σ as the confidence interval
Report "Minimum Guaranteed R2" = mean prediction − 2×standard deviation
F. SHAP Explainability:
After training, compute SHAP values for the best model
Show a feature importance bar chart in the GUI's XAI tab

⚙️ TRAINING STRATEGY
80/20 train-test split, stratified by binned UTS ranges
StandardScaler for all DL and MLP models
For DL models: use Adam optimizer, ReduceLROnPlateau scheduler, early stopping (patience=20)
Batch size: 32 for DL models
Epochs: up to 300 with early stopping
Hyperparameter tuning for top 3 classical models using RandomizedSearchCV (50 iterations, 5-fold CV)
Save every trained model as a .pkl or .pt file in the models/ directory
Report MAE, RMSE, R², and approximate accuracy % for every model on the test set
Auto-select the best model by R² score as the default for prediction
